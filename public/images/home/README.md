# Homepage photography

Seven AI-generated illustrative editorial photographs. These are not client projects, results, endorsements or portraits of SAHIL staff.

Each photograph is supplied as 480 × 320, 960 × 640 and 1536 × 1024 WebP variants. The image manifest in `src/data/homeImages.ts` holds alt text and responsive sources. Full generation prompts are in `docs/home-photography-prompts.json`.

Art direction: varied documentary scenes with natural imperfections and distinct settings: outdoor filming, annotated research, city advertising, writing, projected data, software development and a whiteboard workshop. These replace the original repeated desk compositions.
